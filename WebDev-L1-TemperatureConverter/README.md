# Temperature Converter Website

An interactive temperature conversion website created as part of the Oasis Infobyte Web Development Internship.

## Task

Oasis Infobyte — Web Development & Designing  
Level 1 — Task 3: Temperature Converter Website

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Convert temperature between Celsius, Fahrenheit, and Kelvin
- Numeric temperature input
- Unit selection
- Conversion button
- Clear result display with unit labels
- Input validation
- Absolute zero validation
- User-friendly error messages
- Clean and responsive user interface

## Conversion

The converter supports standard temperature conversion formulas between Celsius, Fahrenheit, and Kelvin.
